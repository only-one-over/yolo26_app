# 标注、数据集与训练

## 标注项目

通过“文件 -> 新建项目”创建工作区。每个项目包含图片、标注、导出数据集、训练输出和项目配置：

```text
my_project/<项目名>/
├── images/                 # 导入的图片和视频帧
├── datasets/               # 导出的 YOLO 数据集
├── models/                 # 导出的模型
├── runs/                   # 训练结果
├── annotations.json        # 自动保存的标注
├── classes.txt             # 类别列表
└── project_config.json     # 项目与训练配置
```

标注会在编辑、切换图片、切换项目和异常退出前自动持久化。恢复项目时，应用会重新读取 `annotations.json`。

## 导入素材

标注页支持以下入口：

| 入口 | 行为 |
| --- | --- |
| 导入图片 | 选择一张或多张图片并复制到项目 `images/` |
| 导入视频 | 按约每秒一帧提取为可标注图片 |
| 导入目录 | 递归扫描目录中的图片和视频；视频同样自动抽帧 |

支持的图片格式包括 JPG、JPEG、PNG、BMP、TIF、TIFF、WebP；支持的视频格式包括 MP4、AVI、MKV、MOV、WMV 和 FLV。重复导入不会重复加入标注列表。

## 标注工具与快捷键

| 工具 | 操作 |
| --- | --- |
| 矩形框 | 按住鼠标拖拽绘制检测框 |
| 多边形 | 逐点点击，双击完成 |
| 关键点 | 逐点放置，双击或 Enter 完成 |
| OBB 旋转框 | 先拖出外接矩形，再拖拽调整角度 |
| 选择 | 选中后移动、编辑或删除标注 |

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Delete` | 删除选中标注 |
| `↑` / `↓` 或 `Shift+Space` | 上一张 / 下一张图片 |
| `R` / `P` / `K` / `O` / `S` | 矩形 / 多边形 / 关键点 / OBB / 选择工具 |

多边形选中后可以拖动顶点；右键顶点删除；双击边插入顶点。清除操作会在执行前要求确认，避免误删当前图片或当前标注区域的内容。

## 辅助标注

### SAM2 交互式分割

1. 在标注页选择 SAM 工具。
2. 加载本地 SAM2 权重或按界面提示下载。
3. 点击目标区域，应用将生成可编辑的分割掩码。

### Grounding DINO 文本检测

输入文本提示词，例如 `person, car`，应用会执行零样本检测并将结果转换为标注。该功能需要单独安装可选依赖，见[环境与模型](environment-and-models.md)。

### YOLO + SAM2 批量标注

该流程适合已有 YOLO 检测模型、但尚未标注的大批量图片：

1. 在测试页加载 YOLO 检测模型。
2. 在标注页加载 SAM2 模型。
3. 导入图片并点击“逐帧检测”。
4. 勾选“使用 SAM2 生成精确掩码”。
5. 人工复核结果后导出 segmentation 数据集。

应用会用 YOLO 边界框作为 SAM2 的 box prompt。单个对象失败只会跳过该对象；取消任务时，已完成的结果会保留。

## 导出 YOLO 数据集

导出后目录结构如下：

```text
<输出目录>/
├── images/
│   ├── train/
│   └── val/
├── labels/
│   ├── train/
│   └── val/
└── data.yaml
```

导出时可设置训练集比例。应用会根据任务类型校验标注：

| 任务 | 输出 |
| --- | --- |
| detect | 矩形框；多边形会转换为外接矩形 |
| segment | 多边形 |
| pose | 矩形框和关键点 |
| OBB | 四角点旋转框 |

当目标目录非空时，应用会创建带时间戳的子目录，避免覆盖已有数据集。

## 训练

训练页支持 detect、segment、classify、pose 任务，以及 YOLO26 和 YOLOv8 模型族。基础流程：

1. 选择导出的 `data.yaml`。
2. 选择任务类型、模型族、模型大小或自定义权重。
3. 设置 epochs、batch、imgsz、device 和优化器。
4. 点击“开始训练”。
5. 在界面查看日志、进度、损失和 mAP 曲线。

训练输出保存于项目 `runs/` 目录，通常最佳权重为 `runs/<实验名>/weights/best.pt`。

### 数据增强

增强采用“预设 + 高级参数”模式：

| 预设 | 适用场景 |
| --- | --- |
| 关闭 | 对照实验或数据已经过外部增强 |
| 轻度 | 小数据集或不希望改变目标几何关系 |
| 默认 | 常规检测训练 |
| 强增强 | 数据量较小、场景变化大时主动选择 |
| 自定义 | 手动调整参数后自动切换 |

颜色增强包括 HSV；几何增强包括旋转、平移、缩放和翻转；组合增强包括 mosaic、mixup、copy-paste、cutmix 与 close_mosaic。训练开始时日志会写入最终生效参数，便于复现和排查。

姿态任务默认不启用垂直翻转；分割任务对 copy-paste 采用保守默认值。详细参数以当前训练页提示和 Ultralytics 官方文档为准。
